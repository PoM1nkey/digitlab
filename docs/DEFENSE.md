## Частые вопросы

**Что разработано самостоятельно?** Предобработка изображений, API,
веб-интерфейс, валидация входа, тесты, конфигурация CI и Docker.
Архитектура и веса CNN взяты из ONNX Model Zoo.

**Где обучение?** Его нет: это прямое требование практикума.

**Зачем FastAPI, если есть Streamlit?** API отделяет модель от пользовательского
интерфейса, его можно использовать независимо и тестировать HTTP контракт.

**Как устроена модель?** Свёрточная нейросеть, обученная на MNIST.
На входе один тензор 1×1×28×28, на выходе десять логитов.
Softmax переводит их в нормированные оценки классов.

**Какая точность?** Назовите фактические значения из artifacts/evaluation.json,
указав первые 1000 изображений тестовой выборки MNIST. Оценка модели и
оценка полного конвейера приведены отдельно. Это не оценка на фотографиях.

**Что будет на картинке кота?** Модель всё равно выберет одну цифру,
поэтому интерфейс предупреждает об ограничениях.

**Что делает CI?** На push и pull request устанавливает зависимости,
загружает проверенную модель, запускает pytest и сохраняет JUnit отчёт.

**Что делает CD?** Если настроен секрет DEPLOY_HOOK, после успешных тестов
push в main запускает развёртывание. Пока секрет не настроен, CD пропускается.
