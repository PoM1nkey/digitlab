# Публикация проекта

Работающее приложение: https://digits-pom1nkey.streamlit.app/
Облачный инференс проверен 24 октября 2026 года.

## Бесплатный Streamlit Community Cloud

1. Войдите на https://share.streamlit.io через свой аккаунт.
2. Нажмите Create app, выберите существующее приложение из GitHub.
3. Репозиторий `PoM1nkey/digitlab`, ветка `main`, основной файл `cloud_app.py`.
4. Выберите Python 3.11 или 3.12 и нажмите Deploy.

`cloud_app.py` запускает FastAPI отдельным процессом на локальном порту 8000,
затем отображает интерфейс Streamlit. При первом запуске скачиваются закреплённые
веса с Hugging Face. Пользователь получает публичную Web ссылку, FastAPI
остаётся внутренним сервисом. Это сохраняет взаимодействие Streamlit + FastAPI.

В форме Hugging Face Spaces, проверенной 24 октября 2026 года для аккаунта
студента, Docker/Gradio требуют платный план. Для бесплатной сдачи используется
Streamlit Community Cloud. Вариант Docker ниже подходит для другого Docker
хостинга или аккаунта с доступным compute.

## GitHub

1. Создайте пустой репозиторий `digitlab` в своём аккаунте GitHub.
2. Не загружайте `.venv`, `.env` и токены. `.gitignore` уже настроен.
3. Загрузите файлы проекта. Если используется Git:

```bash
git add .
git commit -m "Add DigitLab pretrained MNIST service"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/digitlab.git
git push -u origin main
```

Команды предназначены для отдельного репозитория проекта. В уже существующем
репозитории сначала проверьте его ветку и origin, не заменяйте их вслепую.
4. Откройте Actions и дождитесь успешного задания `test`.
5. Сохраните ссылку на запуск Actions для отчёта.

## Облако через Docker

Репозиторий содержит Dockerfile. Можно использовать хостинг Docker, например
Docker Space Hugging Face. Выберите SDK Docker, загрузите файлы и дождитесь
сборки. Фронтенд слушает порт 7860 и обращается к FastAPI на localhost:8000.
Доступность и условия бесплатных ресурсов проверьте в аккаунте перед созданием.

Откройте опубликованный Web интерфейс, выполните распознавание примера.
Сохраните URL и скриншот результата. Такой Web доступ соответствует формулировке
«через Web или API» на странице требований.

Для отдельного API сервиса команда запуска:

```bash
uvicorn digitlab.api:app --host 0.0.0.0 --port 8000
```

На хостингах, назначающих PORT, подставьте значение этой переменной в команду.
До старта выполните `python scripts/download_model.py`.

## Необязательный CD

У облачного провайдера создайте deploy hook и сохраните его URL в GitHub:
Settings → Secrets and variables → Actions → New repository secret,
имя `DEPLOY_HOOK`. URL не коммитьте.

Workflow вызовет hook только после успешных тестов при push в main.
Отключите независимый autodeploy провайдера, если он обходит этот порядок.
При отсутствии секрета шаг явно пропускает публикацию. Успешный HTTP вызов
hook означает принятие запроса, а готовность облачного приложения проверяется
отдельно открытием интерфейса и распознаванием.
