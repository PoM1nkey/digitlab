# Требования проектного практикума

Проверено 24 октября 2026 года в авторизованном курсе КГЭУ.

Источники:
- https://lms2.kgeu.ru/mod/page/view.php?id=14361
- https://lms2.kgeu.ru/mod/assign/view.php?id=14368

Задача: развернуть готовую модель машинного обучения в облаке с доступом
по сети через Web или API. В требованиях указаны команды из 2–3 человек.
Индивидуальное выполнение следует согласовать с преподавателем.

| Требование | Реализация | Что требует внешнего действия |
|---|---|---|
| Предварительно обученная модель | onnxmodelzoo/mnist-12 с Hugging Face | Нет |
| Демонстрация в Google Colab, 20% | notebooks/demo.ipynb | Открыть и выполнить в Colab |
| Код на GitHub, 20% | Полный исходный код и README | Опубликовать в аккаунте студента |
| Streamlit + FastAPI и тесты, 20% | app.py, digitlab/api.py, tests/ | Облачный запуск |
| CI на push | .github/workflows/ci.yml | Первый push и проверка Actions |
| Отчёт и презентация, 40% | Материалы docs и шаблоны курса | ФИО команды, группа, публичные ссылки |
| CD после успешных тестов, повышенная сложность | Зависимый deploy job | DEPLOY_HOOK хостинга |

Наличие конфигурационного файла не доказывает успешную публикацию,
запуск CI или CD. Эти факты нужно подтвердить ссылками и результатами
после выполнения в аккаунтах студента.
